# Парсер цитат с аналитикой (Laboratory Work)

Проект представляет собой ETL-пайплайн (Extract, Transform, Load): сбор данных с веб-сайта, сохранение их в реляционную базу данных и выполнение аналитических запросов.

В качестве источника данных используется учебный сайт [Quotes to Scrape](http://quotes.toscrape.com/).

## Стек технологий

- **Python 3**
- **requests**, **BeautifulSoup4** — парсинг HTML и извлечение данных.
- **SQLAlchemy** (ORM) — работа с базой данных.
- **SQLite** — реляционная база данных для хранения.
- **pandas** — аналитика и агрегация данных.

## Структура проекта

```text
project/
├── models.py          # ORM-модели (таблицы БД)
├── database.py        # Логика сохранения данных (защита от дубликатов)
├── scraper.py         # Парсинг сайта (requests + bs4)
├── main.py            # Точка входа для сбора и сохранения данных
├── analytics.py       # 5 аналитических запросов (SQLAlchemy + pandas)
├── requirements.txt   # Зависимости проекта
├── lab_quotes.db      # Файл базы данных (создается автоматически)
└── README.md          # Документация

Установка и запуск
Установка необходимых библиотек:

pip install requests beautifulsoup4 SQLAlchemy pandas
(Или pip install -r requirements.txt).


Собераем данные и сохраняем их в базу:

python main.py
Скрипт спарсит первые 3 страницы сайта, извлечет цитаты, авторов, их даты рождения и теги. Данные сохранятся в lab_quotes.db.


Запускаем аналитику:

python analytics.py


Особенности реализации:

1. База данных и защита от дубликатов (Идемпотентность)
Для хранения данных используется нормализованная схема из 4 таблиц: Authors, Quotes, Tags и связующая QuoteTags (связь многие-ко-многим).
При повторном запуске парсера дубликаты не создаются. Это реализовано через генерацию MD5-хеша от текста цитаты (quote_hash). Если хеш уже есть в базе, запись пропускается.

2. Аналитика (SQLAlchemy vs Pandas)
В файле analytics.py реализовано 5 различных агрегаций. Каждая агрегация выполнена двумя независимыми способами:

    - SQLAlchemy: соединения (JOIN), группировки (GROUP BY) и агрегатные функции (COUNT, AVG) вычисляются на стороне базы данных.

    - Pandas: данные выгружаются в датафреймы, и все вычисления (слияния merge, группировки groupby, фильтрации) производятся в оперативной памяти с помощью библиотеки Pandas.

Список реализованных запросов:

1. Топ-5 авторов по количеству цитат.

2. Самые популярные теги (Топ-5).

3. Количество цитат у авторов, родившихся до 1950 года.

4. Средняя длина текста цитаты (в символах).

5. Авторы, у которых есть хотя бы одна цитата с тегом 'love'.

6. Лабораторная работа выполнена в рамках курса по обработке данных на Python.
